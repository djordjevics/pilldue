# Getting started

Pilldue is in an early scaffold stage. There is no runnable application yet.

## Clone

```bash
git clone <repository-url>
cd pilldue
```

## Repository layout

| Path | Purpose |
|------|---------|
| `src/` | Application source (empty until a project type is chosen) |
| `docs/` | Project documentation |
| `.cursor/` | Cursor rules and project skills for AI-assisted development |

## Prerequisites

Prerequisites depend on the UI approach (console TUI vs WPF) and will be documented here after that decision.
