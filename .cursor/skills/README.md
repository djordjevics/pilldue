# Project skills

Project-scoped Cursor skills live in this directory. Each skill is a folder with a `SKILL.md` file:

```
.cursor/skills/
  example-skill/
    SKILL.md
```

## github-ticket-flow

Create and update GitHub issues, sub-issues, dependencies, and project status. See [github-ticket-flow/SKILL.md](github-ticket-flow/SKILL.md).

## review-pr

Standards review of a pull request. The user invokes it with `@review-pr` and a PR number. See [review-pr/SKILL.md](review-pr/SKILL.md).
